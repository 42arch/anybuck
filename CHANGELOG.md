## v0.0.2-beta.1 (2026-10-27)

### 🚀 Features

#### English
- Preview release! CloudStore is a cross-cloud object storage management tool designed to manage and transfer data across various cloud storage providers.
- Supports multiple object storage services (e.g., AWS S3, Cloudflare R2, Google Cloud Storage, Alibaba Cloud OSS, Tencent Cloud COS, Volcengine TOS, Qiniu Kodo, etc.).
- Supports cross-provider data transfer and migration.

#### 简体中文
- 预览版发布！CloudStore 是一个跨对象存储服务管理工具，可以管理和传输不同云厂商的对象存储服务。
- 支持对象存储服务（如 AWS S3、Cloudflare R2、Google Cloud Storage、阿里云 OSS、腾讯云 COS、火山引擎 TOS、七牛云 Kodo 等）。
- 支持跨服务商数据传输。
